# TURKI STUDIO — Coffee Shot Calculator

A simple, free, open-source Arabic/English-friendly espresso recipe calculator.

## Features
- Calculate target espresso yield from dose and brew ratio
- Record shot time and roast level
- Save recipes locally in your browser
- Responsive dark coffee-themed interface
- No backend or account required

## Run locally
Open `index.html` in any modern browser.
